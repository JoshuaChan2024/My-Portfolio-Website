SpinAWheel

Web app · 2026

JavaScript CSS

Project Overview

SpinAWheel is a customisable spinning wheel for picking random winners, choosing tasks, or settling small decisions. Users add their own options and spin the wheel.

It was vibe-coded using ChatGPT, and later Claude.

Key features

  • Add and delete members
  • Supports unlimited amount of members

My challenges

When developing the application using ChatGPT, I received vague results that did not fully meet my requirements. After switching to Claude, I used it to improve the code structure, fix errors, refine the user interface, and enhance the overall functionality of the application. It also helped polish the existing features to ensure the application worked more smoothly and aligned better with my original requirements.

Programming languages used

HTML, JavaScript, CSS.
